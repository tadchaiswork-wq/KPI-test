# คู่มือติดตั้ง KPI Dashboard เป็นเว็บแอปจริง (Firebase)

เอกสารนี้พาตั้งแต่ศูนย์จนได้ **เว็บแอปที่มี URL ของตัวเอง** ให้เจ้าหน้าที่ทุกคนเข้าใช้ผ่านเบราว์เซอร์
ล็อกอินด้วย username/password ที่สร้างเอง โดย **ไม่ต้องมีบัญชี claude.ai** ทั้งหมดใช้ของฟรี (Firebase free tier)

ใช้เวลาประมาณ 20–30 นาที และไม่ต้องเขียนโค้ดเพิ่ม แค่คัดลอก-วาง

---

## ไฟล์ในโฟลเดอร์นี้
- `index.html` — ตัวเว็บแอป (ต้องวางค่า Firebase ก่อน 1 จุด)
- `appseed.json` — ข้อมูลตั้งต้น 390 ตัวชี้วัด (ระบบดึงเข้าเองตอนใช้ครั้งแรก)
- `firestore.rules` — กติกาความปลอดภัยของฐานข้อมูล
- `firebase.json`, `.firebaserc` — ไฟล์ตั้งค่า (เฉพาะกรณีใช้ Firebase Hosting)
- `README-TH.md` — คู่มือนี้

---

## สิ่งที่ต้องมี
- บัญชี Google (ฟรี) สำหรับเข้า Firebase Console

---

## ขั้นที่ 1 — สร้างโปรเจกต์ Firebase
1. เข้า https://console.firebase.google.com → **Add project / เพิ่มโปรเจกต์**
2. ตั้งชื่อ เช่น `kpi-cnh` → กด Continue ไปเรื่อย ๆ (จะเปิด Google Analytics หรือไม่ก็ได้) → **Create project**

## ขั้นที่ 2 — เปิดระบบล็อกอิน (Authentication)
1. เมนูซ้าย → **Build → Authentication → Get started**
2. แท็บ **Sign-in method** → เลือก **Email/Password** → เปิด (Enable) อันแรก → **Save**
   - (ไม่ต้องเปิด Email link / passwordless)

## ขั้นที่ 3 — สร้างฐานข้อมูล (Firestore)
1. เมนูซ้าย → **Build → Firestore Database → Create database**
2. เลือกที่ตั้งเซิร์ฟเวอร์ เช่น `asia-southeast1 (Singapore)` (ใกล้ไทยสุด) → Next
3. เลือก **Start in production mode** → Enable

## ขั้นที่ 4 — วางกติกาความปลอดภัย (Rules)
1. ใน Firestore → แท็บ **Rules**
2. ลบข้อความเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ **`firestore.rules`** ในโฟลเดอร์นี้
3. กด **Publish**

## ขั้นที่ 5 — คัดลอกค่า Firebase มาวางในเว็บ
1. เมนูซ้าย ไอคอนเฟือง ⚙️ → **Project settings**
2. เลื่อนลงส่วน **Your apps** → กดไอคอน **`</>` (Web)** → ตั้งชื่อเล่น เช่น `kpi-web` → **Register app**
3. จะเห็นโค้ดชุด `const firebaseConfig = { ... }` — คัดลอกค่าในวงเล็บปีกกา
4. เปิดไฟล์ **`index.html`** ด้วยโปรแกรมแก้ข้อความ (Notepad, VS Code) หา block ที่เขียนว่า
   `⬇️⬇️⬇️ วางค่า Firebase config ของโครงการคุณตรงนี้ ⬇️⬇️⬇️`
   แล้วแทนที่ค่า `PASTE_...` ทั้ง 6 บรรทัดด้วยค่าจริงของคุณ → **บันทึกไฟล์**

ตัวอย่างหลังวางค่าแล้ว:
```
const firebaseConfig = {
  apiKey: "AIzaSyD....",
  authDomain: "kpi-cnh.firebaseapp.com",
  projectId: "kpi-cnh",
  storageBucket: "kpi-cnh.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef123456"
};
```

## ขั้นที่ 6 — อัปโหลดขึ้นเว็บ (เลือกวิธีใดวิธีหนึ่ง)

### วิธี A — Netlify ลากวาง (ง่ายสุด ไม่ต้องลงโปรแกรม) ✅ แนะนำสำหรับเริ่มต้น
1. เข้า https://app.netlify.com → สมัคร/เข้าสู่ระบบ (ฟรี)
2. หน้า Sites → ลาก **ทั้งโฟลเดอร์นี้** ไปวางในกรอบ “drag and drop your site output folder here”
3. รอสักครู่ จะได้ URL เช่น `https://kpi-cnh.netlify.app` (เปลี่ยนชื่อได้ใน Site settings)
4. **สำคัญ:** กลับไป Firebase → Authentication → แท็บ **Settings → Authorized domains → Add domain**
   ใส่โดเมน Netlify ของคุณ (เช่น `kpi-cnh.netlify.app`) → Add
   (ถ้าไม่ทำขั้นนี้ การล็อกอินจะไม่ทำงาน)

### วิธี B — Firebase Hosting (โดเมน .web.app ในตัว, ต้องใช้คำสั่ง)
ต้องมี Node.js ในเครื่อง แล้วเปิด Terminal ในโฟลเดอร์นี้:
```
npm install -g firebase-tools
firebase login
```
แก้ไฟล์ `.firebaserc` เปลี่ยน `PASTE_PROJECT_ID` เป็น project id ของคุณ แล้ว:
```
firebase deploy
```
จะได้ URL เช่น `https://kpi-cnh.web.app` (โดเมนนี้อยู่ใน Authorized domains อยู่แล้ว ไม่ต้องเพิ่ม)

## ขั้นที่ 7 — เริ่มใช้งาน
1. เปิด URL ที่ได้ → กด **สมัครสมาชิก**
2. **คนแรกที่สมัครจะเป็นผู้ดูแลระบบ (admin) อัตโนมัติ** — กรอกชื่อ, username, รหัสผ่าน (≥6 ตัว), เลือกหน่วยงาน
3. เข้าระบบแล้วจะเห็นปุ่ม **“นำเข้าตัวชี้วัดตั้งต้น”** ที่หน้าหลัก → กด 1 ครั้ง ระบบจะดึง 390 ตัวชี้วัดเข้าฐานข้อมูล (ทำครั้งเดียว)
4. เสร็จแล้วใช้งานได้ครบทุกเมนู

## ขั้นที่ 8 — เพิ่มผู้ใช้คนอื่น
- ให้เจ้าหน้าที่แต่ละคนเข้า URL แล้วกด **สมัครสมาชิก** เอง (คนถัดไปเป็น “ผู้รับผิดชอบ” ปกติ)
- admin ไปที่เมนู **ผู้รับผิดชอบตัวชี้วัด → จัดการผู้ใช้งาน** เพื่อกำหนดสิทธิ์/หน่วยงานที่แต่ละคนดูแลได้
- ถ้าต้องการตั้ง admin เพิ่ม: ตอนสมัครใส่รหัส `CNH-ADMIN` ในช่อง “สิทธิ์ผู้ดูแล” **หรือ** ให้ admin เดิมเปลี่ยนสิทธิ์ให้ในเมนูจัดการผู้ใช้

> เปลี่ยนรหัส `CNH-ADMIN` ได้ในไฟล์ `index.html` (ค้นหาคำว่า `CNH-ADMIN`) เพื่อความปลอดภัย ควรตั้งเป็นรหัสลับของคุณเอง

## หมายเหตุความปลอดภัยและค่าใช้จ่าย
- ระบบนี้เหมาะกับใช้ **ภายในโรงพยาบาล** ผู้ที่ล็อกอินแล้ว (บุคลากร) สามารถอ่านทุกตัวชี้วัดและบันทึกผลได้ — เพียงพอสำหรับงาน KPI ภายใน
- รหัสผ่านจัดการโดย Firebase Authentication (ปลอดภัยตามมาตรฐาน ไม่เก็บรหัสเป็น plain text)
- **Free tier (Spark plan)** ของ Firebase: อ่าน 50,000 / เขียน 20,000 ครั้งต่อวัน, เก็บข้อมูล 1 GB — เกินพอสำหรับงานนี้ ไม่ต้องผูกบัตร
- ถ้าต้องการจำกัดสิทธิ์ละเอียดขึ้น (เช่น ให้แก้ไขนิยามตัวชี้วัดได้เฉพาะ admin) ปรับได้ในไฟล์ `firestore.rules`

## การอัปเดตเว็บภายหลัง
- แก้ไฟล์ `index.html` แล้วอัปโหลดใหม่ (ลากวางที่ Netlify อีกครั้ง หรือ `firebase deploy`)
- ข้อมูลในฐานข้อมูลไม่หาย เพราะอยู่ที่ Firestore ไม่ได้อยู่ในไฟล์เว็บ

## เชื่อมกับระบบกลางโรงพยาบาล (อนาคต)
โครงสร้างข้อมูลอยู่ใน Firestore (คอลเลกชัน `indicators`, `results` ในเอกสารตัวชี้วัด, `users`, `chat`, `meta/config`)
สามารถเขียนสคริปต์ import/sync จาก HIS เข้ามาที่ `indicators/<id>.results.<งวด>` ได้ในภายหลัง — ปรึกษาผมได้เมื่อถึงขั้นนั้น
